# Ahaki Study Viewer for Windows

あん摩マッサージ指圧師・はり師・きゅう師の過去問題をWindowsで検索して学習するアプリです。問題、正答、解説は同梱されています。検索、回答、読み上げはオフラインで使用できます。

## インストールする

Windows 11の「設定 → システム → バージョン情報」にある「システムの種類」を確認します。Intel・AMDの64ビットPCは `x64`、SnapdragonなどのARM搭載PCは `arm64` を選びます。`ASV-Windows-0.2.0-x64-Setup.exe` または `ASV-Windows-0.2.0-arm64-Setup.exe` を実行すると、そのWindowsユーザー用にインストールされます。スタートメニューの「ASV」から起動できます。ASVのアカウント登録やAPIキーの入力は不要です。

このインストーラーにはWindowsの発行元署名（Authenticode）が付いていません。学校などの管理端末では実行が制限される場合があり、一般のPCでも初回にSmartScreenの警告が出ることがあります。[Microsoftの配布時の説明](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)

## 問題を解く

起動直後は端末に保存した問題を表示します。初回は同梱の教材を使います。インターネットに接続すると、起動時、再接続時、起動中は1時間ごとにASV Webの公開問題と訂正を取得します。問題文・症例文・選択肢・正答・通常解説の更新は、アプリのアップデートとは別に反映されます。

「設定 → 問題と解説の同期」で最終同期時刻を確認できます。「最新の問題と解説を取得」を押すと、その場で再確認します。通信が途中で切れたときも、次の起動時も、最後に保存を完了した教材を使えます。

左側の検索欄でキーワード、問題番号（例 `A01-001`）、タグ（例 `#呼吸`）を検索できます。「絞り込み」で試験・科目・回数を選べます。問題を選んで回答すると、正誤、正答、解説が表示されます。複数正答や全員正解の採点にも対応します。「もう一度解く」でやり直せます。回答と設定はこのWindowsユーザーの端末に保存します。

「設定」でフォント、14〜40 ptの文字サイズ、行間、ライト・ダーク・システム連動、操作ごとのキー割り当てを変更できます。Windowsのキーボードとスクリーンリーダーで操作できるよう、問題の選択、正誤判定、チャット入力のフォーカスと読み上げ用の名前を設定しています。

| 操作 | 初期設定 |
| --- | --- |
| 検索欄／検索結果へ移動 | Ctrl+F ／ Ctrl+J |
| 前の問題／次の問題 | Ctrl+[ ／ Ctrl+] |
| 選択肢1〜4で回答 | Ctrl+1〜4 |
| もう一度解く | Ctrl+Shift+X |
| 文字を拡大／縮小 | Ctrl+＋ ／ Ctrl+− |
| 問題を読み上げる／停止 | Ctrl+R ／ Ctrl+Shift+R |
| 右のチャットを開く・入力欄へ移動 | Ctrl+Shift+A |
| 質問を送信／入力欄で改行 | Enter ／ Shift+Enter |

### PC-Talkerで本文を読む

検索結果でEnterを押すと、症例文がある問題は症例文の先頭に、それ以外は問題文の先頭にカーソルが移ります。Tabで次の項目、Shift+Tabで前の項目に移れます。症例文・問題文・解説文の中では、左右の矢印キーで1文字ずつ、上下の矢印キーで表示上の1行ずつたどれます。本文は読み取り専用です。

選択肢でEnterを押して回答すると、正誤にフォーカスが移ります。続けてTabを押すと、正答、注記（ある場合）、解説に進みます。Shift+Tabで回答済みの選択肢も読み返せます。PC-Talkerの音声だけで読むときは、「設定 → 読み上げ」の「問題の切り替えと回答時に自動で読む」をオフにします。初期設定はオフです。

## 読み上げと理療科用辞書

Windowsのデスクトップ音声を使用します。「設定 → 読み上げ」で音声、速度、自動読み上げを選べます。日本語音声が一覧にない場合は、Windowsの言語・音声設定で日本語の音声を追加してください。「読み辞書を読み込む…」でお手元の `Jukugo.usr` を選ぶと、問題・選択肢・解説とチャット回答の読み上げに適用します。辞書はユーザーごとに保存します。配布用インストーラーには個人の辞書を含めていません。

## 回答の記録

採点するたびに、端末ごとの匿名ID、問題番号、選んだ選択肢、正誤、回答日時をWeb版と同じ回答統計に記録します。「もう一度解く」で解き直した回答も1回の試行として記録します。送信待ちの回答はアプリを終了しても保存され、次に起動して通信できたときに送信します。「設定 → 回答の記録」で送信待ち件数を確認できます。

## ChatGPTに質問する

問題の「この問題について質問」を押すと右側にチャットが開きます。初回は「Continue with ChatGPT」でブラウザーからご自身のアカウントにサインインし、対応するChatGPTプランの利用を許可してください。質問時には問題・選択肢・正答・解説とその問題の会話をOpenAIに送信します。

入力欄の上のモデル名から、回答モデルとそのモデルが対応する推論エフォートを選びます。変更は次の送信から反映されます。日本語変換中のEnterは変換確定です。回答は見出し・リスト・表を含む書式付きで表示され、読み上げと回答の中止にも対応します。会話と下書きは起動中、問題とアカウントごとに保持します。認証情報はWindowsユーザーに紐づけて暗号化し、モデル・エフォートの選択も保存します。[OpenAIの連携仕様](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)

## 更新する

「設定 → アップデート → アップデートを確認」を選び、新しい版があれば「更新を実施」を押します。Windows版専用の更新情報のEd25519署名と、自分のCPU向けインストーラーのサイズ・SHA-256を検証してからインストールします。初回の更新情報が公開されるまではその旨を表示します。

## ビルド・配布

Node.js 24、npm、Python 3を使用します。Windowsでこのフォルダから実行します。

```powershell
npm ci
npm test
npm run build -- --x64
```

ARM64版の指定は `--arm64` です。インストーラーは `dist` に出力されます。開発時は `npm run data`、`npm start` で起動できます。教材はMac版と同じスクリプトでWeb公開データから生成します。GitHub Actionsの「ASV for Windows」は各CPUのWindowsランナーで実際にインストールし、検索、解答、チャット画面、終了・再起動後の復元を検証してインストーラーを成果物に添付します。

公開者は両方のインストーラーを同じフォルダに置き、ASVの更新署名鍵があるMacで以下を実行します。開発用署名鍵をWindowsやGitHub Actionsにコピーする必要はありません。

```sh
node scripts/sign-update.mjs dist path/to/Sparkle/bin/sign_update
```

GitHub Releasesで `windows-v<バージョン>` タグに2つのインストーラーを添付し、その後、固定タグ `windows-updates` のアセット `windows-update.json` を作成または置き換えます。いずれも「Latest release」に設定しないでください。Mac版の更新は別のフィードを使っています。
