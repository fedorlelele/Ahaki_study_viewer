# Ahaki Study Viewer 利用ガイド

このガイドは、ゲスト・生徒・教師・管理者向けの操作方法をまとめたものです。

## 第1章 まず最初に

### 1-1. 画面の基本構成

- 右上の `☰` ボタン: メニューを開く
- メニュー内:
  - `ログイン`
  - `更新情報`
  - `設定`
  - `学習進捗` (ログインユーザー向け)
  - `利用ガイド`
  - `回答数の推移` (教師/管理者向け)
  - `編集履歴` (教師/管理者向け)
  - `修正提案一覧` (教師/管理者向け)
  - `タグ無効化` (教師/管理者向け)
  - `AI機能公開` (管理者向け)
  - `データ分析` (教師/管理者向け・別ページ)
  - `かんたんビューへのリンク`

### 1-2. 役割ごとの違い

- `ゲスト`: 閲覧と学習が中心
- `生徒`: ゲスト機能 + 学習進捗管理
- `教師`: 生徒機能 + 提案確認/編集履歴/タグ無効化/回答推移
- `管理者`: 教師機能 + 権限管理 + AI機能公開切替

## 第2章 検索の使い方

### 2-1. 検索の流れ

1. 検索ボックスにキーワードを入力
2. 必要に応じて `詳細フィルタ` を開く
3. `検索` ボタンで表示

### 2-2. 入力例

- 通常検索: `循環`
- タグ検索: `#心周期`
- タグAND検索: `#心周期 #刺激伝導系`
- シリアル検索: `A01-001`
- シリアル簡易入力: `a01001`
- 複数シリアル: `A01-001,B22-030,A33-056`

### 2-3. タグ検索の注意点

- 検索欄に `#タグ名` を入力して検索した場合:
  - 科目、小項目、回数などの条件は維持されます。
  - タグは完全一致で検索されます。
- 問題下のタグ説明にある `このタグで検索` を使った場合:
  - 他の検索条件をリセットしてタグ検索します。
- 同義語結合があるタグでは、結果内に `同義語(結合タグ)` が表示されます。

### 2-4. 詳細フィルタ

- 科目
- 小項目
- 種別 (`あん摩マッサージ指圧師` / `はり師・きゅう師`)
- 回数From/To

### 2-5. 並び替え

- 新しい順 / 古い順
- Q&A追加順
- 深掘り解説追加順
- 復習優先順
- 頻出順
- 回答数・正答数・正答率による順序

### 2-6. コマンド検索（検索ボックス内）

検索ボックス内で `@キー=値` の形式を使うと、詳細フィルタを増やさずに複雑な条件を指定できます。

- `@科目=解剖学,生理学`
  - 指定した科目を OR 条件で検索
- `@小項目=感覚,筋`
  - 指定した小項目を OR 条件で検索
- `@種別=A,B`
  - A/B を OR 条件で検索
- `@回数=25..33`
  - 回数範囲（`25-33` も可）
- `@回数=25,27,33`
  - 比較指定（25回以上 / 30回以下）や個別指定にも対応

キーワードはコマンドと併用できます。

- 例: `@科目=生理学 @小項目=感覚,筋 受容器 AND (筋 OR 伸張)`

キーワード条件のルール:

- 空白区切りは AND
- `OR` / `AND`（大文字小文字どちらでも可）
- `,` も OR として扱う
- `"..."` でフレーズ検索
- `()` で優先順位指定

## 第3章 問題の解き方

### 3-1. 回答

1. 問題カードで選択肢を押す
2. 正誤が表示される
3. 設定に応じて正答・解説を表示

### 3-2. コピー機能

- `検索結果をコピー`: 表示中の問題群をまとめてコピー
- 問題カード内アイコン:
  - 問題コピー
  - 追加操作
  - 深掘り解説/深掘り生成
  - Q&A回答コピー (Q&A展開内)
  - 深掘り解説コピー (深掘り表示内)

### 3-3. タグと小項目

- 設定で表示ONにすると問題下に表示
- タグを押すとそのタグで再検索
- タグ説明付きタグは、説明ありと分かる表示で区別
- タグ説明はMarkdown表示に対応

## 第4章 学習進捗 (生徒以上)

### 4-1. 進捗ステータス

- `未着手`
- `理解済み`
- `要復習`

### 4-2. 更新ルール

- 正解すると `理解済み` へ自動更新
- 必要時に `要復習` ボタンで手動変更

### 4-3. 学習進捗パネルでできること

- 自分の進捗サマリー
- 弱点小項目 (科目つき)
- 復習キュー
- 復習キュー全件を検索結果に反映
- 週目標の保存

### 4-4. 端末ローカル回答履歴の取り込み

- ログイン時に取り込み候補があれば確認ダイアログが表示
- 同期していない分がある場合、再ログイン時にも確認

## 第5章 Q&Aと深掘り解説

### 5-1. Q&A

- 各問題の下に過去Q&A一覧を表示
- 質問文を押すと回答を展開
- 回答はMarkdown表示で閲覧
- `いいね` は同一ユーザーで同一質問に1回のみ
- 閲覧数といいね数は表示される

### 5-2. Q&A生成

- デフォルト: 管理者のみ生成可能
- 管理者が `AI機能公開` をONにすると全ユーザーが生成可能
- 公開中は画面上に案内が表示される

### 5-3. 深掘り解説

- ボタンは1つに統合済み
  - 保存済みがあれば「閲覧」
  - 未保存なら「生成」
- 同じボタン再押下で開閉
- 深掘り解説はMarkdown表示で閲覧
- 深掘り解説内のタグを押すと、通常タグと同じ説明パネルを表示

## 第6章 修正要望と編集

### 6-1. ゲスト/生徒

- 修正要望モードONで提案UIが表示
- 症例文、問題文、選択肢、模範解答、解説、タグ、小項目の提案送信が可能

### 6-2. 教師/管理者

- 修正提案一覧で提案確認
- 問題内容の編集・反映
- 解説承認や履歴確認

## 第7章 設定 (ユーザーごと保存)

- 表示モード
- 文字サイズ
- 高コントラスト
- 正答表示/解説表示
- 回答済み問題を表示
- タグ表示
- 小項目表示
- 修正要望モード

設定は端末に保存され、次回アクセス時にも反映されます。

## 第8章 視覚支援のポイント

- 文字サイズ変更と高コントラストを優先設定
- かんたんビューは1問ずつ表示で操作負荷を下げる用途に有効
- 音声読み上げ利用時は、メニューから不要な情報を閉じて使用

## 第9章 よくある質問

### 9-1. データが更新されない

ブラウザの強制リロードを試してください。

### 9-2. ログインできない

- メール/パスワードの再確認
- 権限未付与の場合は管理者/教師に依頼

### 9-3. AI機能が使えない

管理者が公開していない、または日次上限に達している可能性があります。
