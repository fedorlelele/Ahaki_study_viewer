# Ahaki Study Viewer for Mac

あん摩マッサージ指圧師・はり師・きゅう師の過去問題を、Macで検索して解くためのアプリです。macOS 14以降のApple Silicon・Intel Macに対応します。

## 起動と学習

ビルド済みの `build/ASV.app` を開きます。手元で継続して使う場合は「アプリケーション」フォルダにも置けます。

1. サイドバーの検索欄でキーワード、タグ（例 `#呼吸`）、問題番号（例 `A01-001`）を入力します。「絞り込み」では試験・科目・回数を指定できます。
2. 検索結果を選ぶと問題と選択肢を表示します。回答すると正誤、正答、解説を表示します。「もう一度解く」で再挑戦できます。
3. 「読み上げる」で症例文・問題文・選択肢を順に読みます。回答後は正答と解説も読みます。
4. 「ASV」メニューの「設定…」（⌘,）で表示と読み上げを調整できます。外観は「システムに従う」「ライト」「ダーク」、文字サイズは14〜40 pt、行間は0〜18 ptから選べます。

問題データはビルド時点のWeb公開データを同梱します。初版は2026年10月16日版の全10,720問です。検索や回答にはインターネット接続やログインは不要です。回答履歴と設定はこのMacに保存します。教材の更新はMac版のアップデートに含まれます。

## キーボードとVoiceOver

「表示」メニューで文字サイズを変更できます。「学習」メニューには検索・回答用の操作と現在のキー割り当てが表示されます。macOSの「システム設定 → キーボード → キーボードナビゲーション」をオンにすると、Tab・Shift+Tabで各ボタンや設定項目の間を移動できます。「設定 → キーボード」で操作ごとにショートカットを変更できます。

| 操作 | 初期設定 |
| --- | --- |
| 文字を拡大・縮小（2 ptずつ） | ⌘＋・⌘− |
| 検索欄へ移動 | ⌘F |
| 検索結果へ移動 | ⌘J、続いて上下矢印で選択 |
| 前の問題・次の問題 | ⌘[・⌘] |
| 選択肢1〜4で回答 | ⌘1〜⌘4 |
| もう一度解く | ⇧⌘X |
| 読み上げる・停止する | ⌘R・⇧⌘R |
| 右の質問サイドバーを開く・入力欄に移動 | ⇧⌘A |
| 質問を送信・入力欄で改行 | Enter・Shift+Enter |

JIS配列では、⌘とShiftを押しながら「れ／;」キーで＋を入力します。US配列では⌘とShiftを押しながら「=」キーを使います。

回答すると結果の見出しに、再挑戦すると最初の選択肢にフォーカスが移ります。VoiceOverで正誤と検索件数を確認できます。問題の切り替えと回答時に日本語音声で自動読み上げを行う設定もあります。

## 理療科用読み辞書

「設定 → 読み上げ → 読み辞書を読み込む…」で、日本理療科教員連盟の理療科用読み辞書「読ター」の `Jukugo.usr` を選びます。登録語数を確認したら、問題・選択肢・解説・チャットの回答に辞書の読みが適用されます。辞書はこのMacに保存され、次回の起動時にも利用できます。「理療科用読み辞書を使う」で標準の読みとの切り替えができます。

## ChatGPTに質問する

1. 問題の「この問題について質問」またはツールバーの質問ボタンで、右側のチャットを開きます。初回は **Continue with ChatGPT** でサインインし、ChatGPTプランの利用を許可します。
2. 質問入力欄のすぐ上にある現在のモデル名のボタンを開きます。VoiceOverでは「モデルとエフォート」と読み上げます。「回答モデル」を開くと、このアカウントで使えるモデルから選べます。「エフォート（推論の強さ）」はモデルごとに選べます。「自動」はモデルの既定値を使います。
3. 質問を入力し、Enterで送信します。モデルとエフォートの変更は次に送る質問から反映され、同じ問題の会話を続けられます。日本語変換中のEnterは変換を確定し、Shift+Enterは改行を入力します。
4. 回答の見出し・箇条書き・表は書式付きで表示されます。別の問題を選ぶと、その問題の会話に切り替わります。会話はアプリを開いている間、問題とアカウントごとに保持します。

選んだモデルはアカウントごとに、エフォートはそのアカウントのモデルごとにこのMacに保存します。以前使ったモデルに戻すと、そのときのエフォートも復元されます。使えるモデルを再確認するには、同じ画面で「モデル一覧を更新」を選びます。

送信時は、表示中の問題の番号・試験・科目・本文・選択肢・正答・解説と、その問題で交わした会話をOpenAIに送ります。認証情報はmacOSのキーチェーンに保存します。アカウント切り替え、サインアウト、利用状況の確認は質問画面または設定から行えます。この連携にはOpenAI公式のローカルアプリ向けOAuthフローとResponses APIを使用します。[OpenAIの連携仕様](https://developers.openai.com/siwc/token-sharing-open-source)

## アップデート

「ASV → アップデートを確認…」を選びます。新しい版があると、Sparkleが署名を検証し、画面からインストールと再起動ができます。公開済みの更新がない場合はその旨を表示します。配布者向けの手順は[リリース手順](Packaging/RELEASING.md)にあります。

## 開発

リポジトリのルートから実行します。Xcode 15以降のSwift環境とPython 3.9以降を使用します。初回ビルド時はSwiftPMがGitHubからSparkleを取得します。

```sh
swift test --package-path mac_app
python3 mac_app/scripts/build_app.py --universal
open mac_app/build/ASV.app
```

SwiftUI画面と日本語読み上げは `Sources/ASVMac`、教材検索と採点は `Sources/ASVData`、認証と質問は `Sources/ASVChat`、更新は `Sources/ASVUpdate` にあります。GitHub ActionsはMac上でテストと両アーキテクチャのビルドを行い、実行結果にアプリのZIPを添付します。
