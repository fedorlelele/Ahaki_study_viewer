# Ahaki Study Viewer 利用ガイド（ゲスト / 生徒 / 教師 / 管理者）

## ゲストユーザー
- 検索: キーワードで絞り込み。タグは `#タグ名` で検索できます。シリアルは `A01-001` / `a01001` / `A01-001,A02-003` のように検索できます。
- 絞り込み: 科目 / 小項目 / 種別 / 回数で絞り込めます。
- 頻出: タグの出現頻度を元に「頻出」を自動判定します（並び替えや「頻出のみ」フィルタで活用できます）。
- 表示: 回答済みラベルと頻出ラベルが問題一覧に表示されます。
- 解答: 選択肢をクリックすると正答・解説が表示されます。
- コピー: 「この問題をコピー」で問題文をコピーできます。
- 要望: タグ / 小項目 / 解説の「修正を要望」からコメントを送信できます（必須）。

## サインアップ/ログイン
- 画面上部の「教師ログイン」パネル内の「サインアップ」から登録します。
- 登録直後は未承認のため、編集機能は使えません。
- 権限は管理者または教師が付与します。

## 生徒ユーザー
- ログイン: 画面上部の「教師ログイン」からログインします。
- ゲストと同じ機能が利用できます（追加機能は順次拡張予定）。

## 教師ユーザー
- ログイン: 画面上部の「教師ログイン」からログインします。
- 編集: 解説・タグ・小項目の編集提案を送信できます。
- 承認: 解説を承認して「AI承認済」にできます。
- 提案一覧: 画面上部の「修正提案一覧」から未処理の提案を確認できます。

## 管理者ユーザー
- ログイン後、「管理画面を開く」から権限変更やユーザー管理ができます。

## 更新情報
- 「更新情報」を開くと、解説追加数や機能更新の履歴を確認できます。

## 注意
- ログインしない場合は編集機能は利用できません。
