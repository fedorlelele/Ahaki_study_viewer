Ahaki かんたんビュー

視覚障害者・音声操作向けの簡易インターフェース
高機能ビューを開く プリント作成ビュー データ分析へ
操作手順
  1. 科目を選択してください。
  2. 小項目を選択してください（すべてでも可）。
  3. 試験種別を選択してください。
  4. 問題が1問ずつ表示されます。矢印キーまたは数字キーで選択肢を動かし、Enterで回答します。
  5. Tabキーで次の項目に移動できます。

キーボード: ↑↓で選択 / 数字キーで直接選択 / Enterで回答 / Tabで項目移動
